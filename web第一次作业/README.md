# 第一次作业：个人简介网页

## 作业内容

完成个人简介HTML网页作业，编写index.html页面展示个人姓名、籍贯、学校专业、自我介绍、兴趣爱好、联系方式。遵循HTML代码编写规范，添加注释，使用相对路径引用图片，最后将`index.html`和`README.md`提交到GitHub仓库，提交commit信息为“第一次作业：个人简介”。

## 使用到的标签

- 文档基础：`<!doctype html>`、`<html>`、`<head>`、`<body>`
- 元数据：`<meta>`
- 标题：`<title>`、`<h1>`、`<h2>`
- 文本相关：`<p>`、`<strong>`加粗、`<em>`斜体、`<hr>`分割线、`<br>`换行
- 图片：`<img>`
- 超链接：`<a>`（包含`target="_blank"`新窗口打开、`mailto:`邮箱链接）
- 注释：`<!-- -->`

## 遇到的困难及解决方法

1. **邮箱链接无效**：一开始忘记加`mailto:`协议，点击邮箱没有反应，检查代码时发现没有加协议，添加后正常打开。
2. **代码格式规范**：部分a标签换行比较零散，统一调整缩进为4空格，标签小写、属性全部使用双引号，增加多处注释满足作业注释数量要求。
3. **GitHub提交**：需要把index.html和README.md一起上传仓库，注意commit提交消息严格按照作业要求填写为“第一次作业：个人简介”。
