# 第一次作业：个人简介网页

### 作业内容

制作一个个人简介HTML网页，展示个人基本信息、个人介绍、兴趣爱好以及多种联系方式，按照HTML代码规范编写，最终提交到GitHub仓库。

### 使用到的HTML标签

- 结构标签：`<!doctype html>`、`<html>`、`<head>`、`<body>`
- 标题标签：`<h1>`、`<h2>`
- 文本段落：`<p>`、`<strong>`（加粗）、`<em>`（斜体）、`<br>`（换行）、`<hr>`（分割线）
- 图片标签：`<img>`
- 超链接标签：`<a>`（包含mailto邮箱链接、新窗口打开属性target="\_blank"）
- 注释标签：`<!-- -->`

## 遇到的困难及解决方法

1. **邮箱链接无效**：一开始忘记加`mailto:`协议，点击邮箱没有反应，检查代码时发现没有加协议，添加后正常打开。
2. **代码格式规范**：部分a标签换行比较零散，统一调整缩进为4空格，标签小写、属性全部使用双引号，增加多处注释满足作业注释数量要求。
3. **GitHub提交**：需要把index.html和README.md一起上传仓库，注意commit提交消息严格按照作业要求填写为“第一次作业：个人简介”。
