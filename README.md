# 第二次作业：用户注册页面

## 作业内容

制作一个完整的"用户注册"页面，综合运用 HTML5 的列表、表格、表单三大模块知识。

## 使用到的标签

### 1. 语义化结构标签

- `<header>` — 页面头部，包含主标题
- `<main>` — 主体内容区域
- `<footer>` — 页面底部，包含版权信息
- `<h1>` — 页面主标题

### 2. 表格标签

- `<table>` — 注册须知表格
- `<thead>` / `<tbody>` — 表头与表体划分
- `<th>` — 表头单元格
- `<td>` — 数据单元格
- `colspan="2"` — 合并列（填写要求、提示信息）
- `rowspan="2"` — 合并行（填写项目、其他信息）

### 3. 列表标签

- `<ol>` — 有序列表，展示注册步骤
- `<ul>` — 无序列表，展示注意事项
- `<dl>` / `<dt>` / `<dd>` — 定义列表，展示常见问题

### 4. 表单标签

- `<form>` — 注册表单
- `<input>` — 文本框、密码框、单选框、复选框、文件上传等
  - `type="text"` — 用户名
  - `type="password"` — 密码、确认密码
  - `type="radio"` — 性别
  - `type="checkbox"` — 兴趣爱好
  - `type="file"` — 头像上传
  - `type="date"` — 出生日期（HTML5 新增）
  - `type="email"` — 邮箱（HTML5 新增）
  - `type="tel"` — 手机号
- `<select>` / `<option>` — 所在城市下拉选择
- `<textarea>` — 个人简介多行文本
- `<button>` — 提交和重置按钮
- `<label>` — 两种用法：包裹式、for/id 关联式

### 5. 验证属性

- `required` — 必填校验（用户名、密码、确认密码、邮箱）
- `pattern="[0-9]{11}"` — 手机号正则校验
- `placeholder` — 密码输入提示

### 6. JavaScript

- 监听 `submit` 事件，阻止默认提交
- 密码一致性校验
- 使用 `FormData` 收集表单数据
- 在 Console 面板打印所有字段值

## 遇到的困难及解决方法

### 困难 1：表格边框显示异常

**问题**：将 `border="1"` 从 HTML 移到 CSS 后，表格边框变成单线，和原来效果不同。
**解决**：在 CSS 中添加 `border-collapse: collapse` 合并边框，并为 `th` 和 `td` 分别设置边框，恢复双线表格效果。

### 困难 2：两种 label 用法的选择

**问题**：教材要求两种 label 用法至少各用一次，不确定何时用包裹式、何时用 for/id 式。
**解决**：单选框/复选框组使用包裹式 `<label><input> 文字</label>` 更简洁；需要单独定位时使用 for/id 式 `<label for="id">`。

### 困难 3：表单数据收集时复选框只显示一个值

**问题**：兴趣爱好有多个复选框，用 `formData.get("hobby")` 只能获取第一个选中的值。
**解决**：使用 `formData.getAll("hobby")` 获取所有选中的值，再用 `.join(", ")` 拼接成字符串。

## 文件说明

- `index.html` — 主页面文件，包含完整 HTML 结构
- `style.css` — 外部样式表，控制表格边框等样式
- `README.md` — 本说明文件

## 测试方法

1. 用浏览器打开 `index.html`
2. 填写表单信息，点击"注册"按钮
3. 按 F12 打开开发者工具
4. 在 Elements 面板检查 DOM 结构
5. 在 Console 面板查看收集到的表单数据
